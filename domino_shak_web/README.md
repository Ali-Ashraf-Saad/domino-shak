# Domino Shak — deployable website

This directory is the static web deployment copy. It is generated by
`../tools/sync_web_assets.sh` from the canonical bundled game source:

`../domino_shak_app/assets/web/index.html`

The historical original `../index.html` is never read or modified by the sync.

## Contents

- `index.html` — self-contained Arabic RTL game.
- `assets/fonts/` — locally hosted fonts and licences.
- `vendor/peerjs/peerjs.min.js` — PeerJS 1.5.4, same version as the Android app.
- `PRIVACY_POLICY.html` — policy page used by in-app links.
- `config.js` — informational constants only; the game does not depend on it.
- `.well-known/assetlinks.json` — generated from the template until the real
  Play App Signing fingerprint is supplied. It must not be treated as valid
  while it contains `REPLACE_WITH_PLAY_APP_SIGNING_SHA256`.
- `SHA256SUMS.txt` — generated checksum manifest.

## Regenerate after source changes

```bash
cd /home/ali/Documents/DominoGame
bash tools/sync_web_assets.sh
```

To generate a real App Links file:

```bash
PLAY_APP_SIGNING_SHA256="AA:BB:..." bash tools/sync_web_assets.sh
```

Do not upload the placeholder as a production association file.

## Hosting restrictions

The host supports PHP, HTML, CSS and JavaScript. No Node.js, Python or custom
long-running server is used. Online multiplayer remains PeerJS/WebRTC.

See `WEB_DEPLOYMENT_GUIDE.md` in the project root and
`deployment/upload_instructions.md` in this directory.
